## Introduction

For my software design and engineering enhancement, I used my Travlr application to demonstrate the software development skills I gained throughout my Computer Science program. Working with an existing application helped me understand the importance of organizing code, maintaining functionality, and making improvements without disrupting the rest of the system. This enhancement allowed me to apply concepts related to full stack development, application structure, maintainability, and testing.

## Project Overview

The Travlr application uses a full stack architecture that connects the user interface with back end services and database functionality. Its project structure separates responsibilities into different files and folders, making it easier to understand how the application operates. The front end supports interactions with users, while the back end processes requests and provides access to application data.

Reviewing this structure helped me better understand how different parts of an application depend on one another. It also showed me why developers need to consider the overall design of a project instead of focusing only on individual files.

## Enhancement and Design Improvements

My work on the Travlr project focused on improving my understanding of the existing code, maintaining the organization of the application, and evaluating how its components work together. I considered the importance of clear file organization, readable code, and separating application responsibilities.

These practices make software easier to maintain because developers can identify where specific functionality belongs and make changes more carefully. I also recognized that software improvements should be based on project requirements and verified through testing. Maintaining existing functionality is important when updating an application because changes to one component can affect other parts of the system.

## Testing and Maintainability

Testing is an important part of software design and engineering. After making changes, developers should verify that the application behaves as expected and that existing features continue to work. Testing also helps identify errors that may not be obvious when reviewing code alone.

This project reinforced the value of reviewing changes, checking application behavior, and keeping the code organized. In a professional development environment, these practices help reduce maintenance problems and make it easier for other developers to understand and continue working on a project.

## Skills and Professional Growth

This enhancement helped me connect the concepts I learned in class to a larger software application. I developed a stronger understanding of full stack architecture, code organization, maintainability, and the importance of testing. I also learned that effective software development requires patience and attention to detail because even small changes can affect the behavior of an application.

These skills will help me continue improving as a computer science professional. Understanding how to work with existing software is especially valuable because developers often need to maintain or enhance applications that were created by someone else.

The software design and engineering enhancement demonstrates my understanding of application structure and the practices that support maintainable software.
