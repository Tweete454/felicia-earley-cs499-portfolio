## Introduction

Databases are an important part of computer science because they allow applications to store, organize, retrieve, and manage information. For my CS 499 capstone, I used the Travlr application to demonstrate my understanding of database concepts and how databases support full stack development. Working with this project helped me better understand the relationship between an application's back end, its data models, and its database.

## Project Overview

The Travlr application uses a back end to handle application requests and work with stored information. Its models and related components help define how data is represented and accessed. The database supports the application by allowing information to be stored and retrieved when needed.

Reviewing the project helped me understand why database functionality must work correctly with the rest of the application. Even when a database is configured properly, problems in the models or back end can affect how information is processed and displayed.

## Database Design and Functionality

Good database design helps maintain accurate and organized information. Developers need to consider how data is structured, how records are accessed, and how application components communicate with the database. They must also consider validation and error handling to help prevent incorrect or unexpected data from causing problems.

During my work with Travlr, I focused on understanding the database-related structure of the project and the role that data handling plays in application functionality. This helped me recognize the importance of maintaining consistency between the data models and the operations performed by the application.

## Testing and Reliability

Testing database functionality is necessary to make sure information can be handled correctly. Developers should verify that expected data can be created, retrieved, updated, and deleted when those operations are supported. They should also check how the application responds when data is missing, invalid, or unavailable.

Testing these behaviors helps identify problems before an application is used in a real environment. It is also important to protect database credentials and other sensitive information instead of placing them directly in publicly accessible source code.
