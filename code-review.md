## Software Design and Engineering

The Travlr application uses a full stack structure that separates different responsibilities across the application. The front end handles the user interface, while the back end processes requests and connects application functionality to the data layer. This separation makes it easier to maintain and update individual parts of the project.

During my review, I considered the organization of the application files, the relationship between the front end and back end, and opportunities to improve the maintainability of the code. I also considered how clear organization and consistent coding practices can make an application easier for other developers to understand. These improvements are important because software should be designed so it can be maintained and expanded as requirements change.

## Algorithms and Data Structures

Algorithms and data structures are important because they determine how applications process, organize, and retrieve information. While reviewing the Travlr application, I considered how its existing logic handles data and how code organization affects readability and performance.

An important part of software development is selecting appropriate methods for processing information while avoiding unnecessary complexity. Clear and efficient code makes applications easier to test, maintain, and improve. This area of the project helped me connect programming concepts from my coursework to the practical requirements of a larger application.

## Databases

The database component of the Travlr application supports the storage and retrieval of application information. Reviewing this component helped me consider how data models, database queries, and the back end work together to provide application functionality.

Database development requires attention to data consistency, appropriate data handling, and reliable communication between application components. My database enhancement focused on improving my understanding of how the application manages information and how database-related code contributes to the overall system. This experience reinforced the importance of testing database functionality and ensuring that changes do not interfere with existing application features.

## Security and Testing

Security and testing are important considerations when developing a full stack application. An application that manages information must protect access to restricted functionality and handle requests appropriately. During my project work, I considered the importance of authentication, access control, and testing application behavior.

Testing helps developers identify problems before changes are considered complete. It is important to verify expected behavior, review error conditions, and confirm that existing functionality continues to work after modifications. This process helped me understand why developers should evaluate both individual components and how those components work together.
